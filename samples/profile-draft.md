**기본 (4문장)**

> SI 회사에서 약 6년간 웹과 앱의 프론트엔드를 개발했습니다. 신규 서비스를 처음부터 세우는 일과 이미 돌아가는 서비스를 이어받아 고치는 일을 모두 해왔고, 대부분의 프로젝트에서 프론트엔드를 1~2명 규모로 맡아 화면 전체를 책임졌습니다. 기술을 고르고 개발 방식을 정하는 일부터 현업과 요구사항을 조율하는 일까지 함께 해왔습니다.

### 풀스택 확장의 근거로 쓸 수 있는 것

「이미 백엔드를 했다」가 아니라 **「프론트엔드 밖으로 나가본 접점」**으로 쓰는 편이 정확합니다.

- 프론트엔드 관련 AWS 세팅 전담과 ECS·Docker 배포 자동화 구성 (부스트리)
- Spring 기반 서비스에서 Maven 빌드에 React 빌드를 편입 (민팃)
- 서버와의 역할 분담 설계 — 클라이언트 입력과 서버 조회의 경계, 결제 금액 비교 시점 (플러스팟·SK 쉴더스)
- 배포·롤백 운영 (부스트리 ECS 롤백, 에코야·플러스팟 CloudFront 캐시 무효화)

> 백엔드 코드를 직접 작성한 경험은 확인되지 않았습니다. 「Spring 환경에서 작업했다」와 「백엔드를 개발했다」는 다르며, 후자로 쓰지 않습니다.
