# Blog Category / Tag Codes — Sample

블로그 front matter는 표시명(`아키텍처`, `폐쇄망`)을 쓴다. DB의 `code`는 소문자·숫자·하이픈만 허용하므로 시드 도구가 이 표로 코드를 정한다.
표에 없는 이름은 시드가 실패한다(추측으로 코드를 만들지 않는다).
