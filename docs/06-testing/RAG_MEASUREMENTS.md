# RAG Measurements

측정 결과의 기준 문서다. 다른 문서는 여기의 수치를 복제하지 않고 링크한다.

```bash
python3 poc/rag_eval.py search --save     # OPENAI_API_KEY 필요
python3 poc/rag_eval.py answer --save     # OPENAI_API_KEY 필요
```

| 전략 | 청크 수 | 최소 | 중앙 | 최대 | 200자 미만 | 1200자 초과 | 복수 섹션 |

"섹션이 길어서 쪼개야 한다"는 ERD 작성 시점의 가정이 이 콘텐츠 규모에서 틀렸음을 보여준다.

## 측정 5 — 고정 질문(FAQ) 매칭 거리 (2026-09-17)

`poc/faq_threshold.py`로 짧은 질문끼리의 코사인 거리(`text-embedding-3-small`)를 쟀다. 등록 질문 3개(사는 곳·연락 방법·이직 준비), 방문자 질문 22개(같은 뜻 10, 다른 뜻 12). 사용자 로컬 실행 결과. JSON 원본은 저장되지 않아 콘솔 출력에서 옮겼다.

- 같은 뜻 중 가장 먼 거리 0.7338, 다른 뜻 중 가장 가까운 거리 0.6305 → **겹침.**
- 같은 뜻 10개 중 3개는 다른 FAQ가 더 가까웠다: "집이 어디세요?"→이직(0.6767), "채용 제안을 받고 계신가요?"→연락(0.7586), "새로운 회사를 찾고 계세요?"→사는 곳(0.8018).
- 다른 뜻인 "어디서 일하세요?"(0.6305)가 같은 뜻인 "사는 곳이 어디예요?"(0.6583)보다 가까웠다.
- 거리 0.6 미만은 같은 뜻 4개뿐이고 다른 뜻은 없었다(0.3081~0.5905).

**해석:** 짧은 한국어 질문끼리는 임베딩 거리만으로 같은 뜻을 가를 수 없다. 거리 하나로 고정 답변을 내보내면 오답 위험이 있거나(느슨한 기준), 대부분 놓친다(빡빡한 기준). 측정 2의 "근거 있음/없음" 분리 실패와 같은 성격이다.

- **6/6 기대대로.** 측정 5에서 거리가 엇나갔던 "집이 어디세요?"도 등록 답변이 나왔고, 거리가 가까웠던 "어디서 일하세요?"는 FAQ를 쓰지 않았다. 거리 대신 모델 판단(ADR-0014)이 유효했다.
- 등록 답변 문장이 그대로 쓰였다(인용 번호만 추가).
- `[[NO_ANSWER]]` 표시는 답변에 노출되지 않았고 `unanswered`로 반영됐다.
- 개선 후보: 주제 자리에 질문 문장이 그대로 들어간 경우가 있다("어디서 일하세요?에 대해서는"). 주제를 명사형으로 쓰라는 지시를 추가할지 검토한다.
- 미측정: 바뀐 프롬프트로 PoC 질문 7개 중 근거 있는 6개 재확인(표시 오판정 여부).

## 측정 8 — FAQ와 비슷한 질문 (2026-09-17, 사용자 로컬)

FAQ "고향이 어디세요?" 등록 상태에서 실제 모델로 확인했다.

| 프롬프트 | "어디서 태어나셨나요?" | "어디서 일하세요?" | "고향이랑 주로 쓰는 기술 알려주세요" |
|---|---|---|---|
| 측정 7 기준 | 등록 답변 + 안내 문구(미답변 기록) | — | — |
| 비슷한 질문 규칙 추가(안내 규칙 뒤) | 안내 문구만 (기대와 다름) | 안내 문구만 (기대대로) | 두 내용 모두 답변 (기대대로) |

- 해석: 표시(`[[NO_ANSWER]]`)는 답변 맨 앞에 써야 해서 모델이 FAQ 규칙을 읽기 전에 판단하는 순서가 됐을 가능성. FAQ 규칙을 안내 규칙 앞으로 옮기고 "이 경우는 근거로 답할 수 있는 질문으로 본다"를 추가했다. 재확인 대기.
- 미확인: 이 질문에서 FAQ 문서가 검색 상위 5건에 들었는지(어드민 미답변 목록의 검색 문서로 확인 가능).
- 순서 변경 후에도 같은 질문에서 두 답이 번갈아 나왔다: ① 판단 과정 서술 + 안내 문구, ② "고향이 어디세요?라는 질문에 대한 답변으로 대신할 수 있습니다. 저의 고향은 안산입니다[2]." → 프롬프트만으로는 일관성을 보장할 수 없다고 보고 판정 단계를 분리했다(ADR-0014 후속 결정 2).
- 판정 단계 분리 후(사용자 로컬, 질문별 2~3회): "어디서 태어나셨나요?" 매번 등록 답변만, "어디서 일하세요?" 매번 안내 문구, "고향이랑 주로 쓰는 기술 알려주세요" 매번 두 내용 모두 답변. 판단 과정 노출 없음.
