## 프로젝트 개요

민팃은 중고폰 재활용과 기부를 편하게 할 수 있게 해 주는 서비스입니다. 저는 약 1년 6개월 동안 프론트엔드를 혼자 맡아 국내 B2C 웹, 관리자 BOS, CES 2022 홍보 페이지, 일본향 베타 서비스 페이지를 개발했습니다.

작업은 랜딩 페이지 리뉴얼, 이벤트 페이지 신규 개발, 유지보수 순서로 진행했습니다. 기존 서비스는 Java Spring의 Thymeleaf·JSP 템플릿 페이지마다 Vue.js를 불러 쓰는 구조였고, 이벤트 페이지는 React로 만들어 Spring 빌드 과정에 포함했습니다.

개발 PL로 현업과 직접 소통하며 요구사항을 조율했습니다.

## 주요 성과

- 약 1년 6개월 동안 B2C 웹과 BOS의 프론트엔드를 혼자 맡아 리뉴얼, 신규 개발, 유지보수를 이어 갔습니다.
- 기존 Thymeleaf + Vue.js 환경에서 B2C 랜딩 페이지 전체를 새로 만들었습니다.
- 새로 여는 이벤트 페이지를 React로 개발했습니다. Maven 빌드에 React 빌드를 넣고 산출물이 서버가 찾는 `index.html` 위치에 놓이도록 설정해, 기존 배포 흐름 안에서 함께 배포되게 했습니다.
- JSP 템플릿 + Vue.js 기반 관리자 웹을 유지보수했습니다.
- CES 2022 홍보 페이지와 일본향 베타 서비스의 브랜딩 페이지·계좌 입력 페이지를 개발했습니다.
