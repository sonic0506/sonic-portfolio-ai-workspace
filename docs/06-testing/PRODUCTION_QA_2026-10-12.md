대상: `https://www.sonic-portfolio.com` (포트폴리오 공개 화면) + `https://api.sonic-portfolio.com` 공개 API.

## 정상으로 확인한 것

- 전 경로 200, apex·http → `https://www` 308, ISR HIT, API health UP, 목록 API 응답 60~100ms.
- 데이터 정합: 프로젝트 13(대표 3), 블로그 98, 카테고리 9개 합계 98 = 사이드바 숫자와 일치. 블로그 slug 중복 없음.

- 다크 모드: 본문·카드·스킬 아이콘·그래프 모두 읽힘.
- 블로그: 페이지네이션(20개씩 5쪽), 검색 모달(결과 17건, 결과 없음 문구), 목차, 이전/다음, 참고 문서.
- 채팅: SSE 스트리밍, 근거 문서 링크, 후속 질문 문맥 유지("그 프로젝트" → 순찰 로봇), 근거 없는 질문 거부, 새로고침 후 대화 복원.
