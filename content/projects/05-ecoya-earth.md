## 프로젝트 개요

사용자가 재활용품을 분류해서 내놓으면 수거해 가고, 대가로 탄소중립포인트와 앱 포인트를 주는 친환경 서비스입니다. 앱 포인트로는 응모·기부 프로모션에 참여할 수 있고, 제가 만든 앱 내 WebView가 이 프로모션 콘텐츠를 보여 주는 화면입니다.

초기 기획부터 웹 개발 PL로 참여해 관리자 웹, 콘텐츠 WebView, 제휴사 웹앱, B2C 랜딩 페이지를 만들었습니다. 웹 작업은 ‘관리자 웹·콘텐츠 WebView’, ‘제휴사 웹’, ‘랜딩 페이지’ 세 프로젝트로 나눴습니다. 고객 앱은 앱 개발자가 따로 맡았습니다. 제휴사 웹앱은 파트너사가 우리 서비스를 제공할 때 쓰는 휴대폰 브라우저용 웹입니다.

| 항목 | 내용 |
|---|---|
| 팀 구성 | 웹 프론트엔드 2명(본인 포함), 앱 프론트엔드 1명, 서버 2명, 디자이너 1명, PM 1명 |
| 나의 역할 | 웹 개발 PL, 관리자·콘텐츠 WebView·제휴사 웹앱·랜딩 페이지 개발, 콘텐츠 템플릿·데이터 치환·미리보기 구조 직접 설계·구현, S3·CloudFront 설정 |

## 주요 성과

- **관리자와 여러 웹 서비스 개발:** React로 관리자 웹과 앱 포인트를 쓰는 응모·기부 콘텐츠 WebView를, Next.js로 B2C 랜딩 페이지와 제휴사용 웹앱을 만들었습니다.
- **콘텐츠 표시 구조 직접 설계:** 관리자가 설정한 콘텐츠가 파트너 웹과 B2C 앱에서 같은 규칙으로 보이도록 HTML 템플릿, 데이터 치환, 미리보기 구조를 직접 설계해 만들었습니다. 각 클라이언트에 필요한 공통 로직은 함수로 묶어 넘겼습니다.
- **제휴사 링크와 제공 서비스 구성:** 관리자에서 제휴사를 등록하면 제휴사용 링크가 만들어지고, 제휴사마다 고른 서비스의 콘텐츠만 보이게 했습니다. 제휴사 웹은 플래그로 들어오면 서버에서 검증하는 구조였습니다.
- **모바일 웹의 탐색·입력 흐름 개발과 검수:** 휴대폰 브라우저용 파트너 웹앱을 만들면서 뒤로가기와 바텀시트, 여러 단계 입력, 작성 중에 화면을 떠나는 경우를 챙겼습니다. Android·iOS 테스트 폰으로 직접 확인했습니다.
- **배포 환경 설정:** Amazon S3와 CloudFront를 설정해 웹 배포 환경을 만들었습니다.
