# ADR-0004: RAG Answer and Session Policy

- Status: Accepted
- Date: 2026-09-09

## Context

사용자가 공개 콘텐츠 기반·출처 표시·근거 부족 명시 정책을 채택하고, 대화 세션별 이전 질문 기억을 요청했다.

## Decision

- Public 챗봇은 공개된 콘텐츠만 근거로 사용한다. Draft/비공개/삭제/발행 취소 콘텐츠는 검색과 Relation 확장 및 답변 출처에서 제외한다.
- 근거가 있는 답변에는 사용한 공개 원문 출처를 표시한다. 근거가 부족하면 부족함을 명시하고 사실을 만들어내지 않는다.
- 같은 대화 세션의 이전 질문과 답변을 후속 질문 이해에 활용한다. 새 세션에는 다른 세션의 이력을 전달하지 않는다.
- 대화 이력은 질문 해석을 위한 맥락이며 포트폴리오 사실의 검증된 근거를 대체하지 않는다. 이전 답변을 반복하기 전에 현재 공개 근거를 확인한다.

## Alternatives Considered

- 매 질문 독립 처리: 사용자가 세션별 기억 방식을 선택했다.
- 세션 간 공통 기억: 요청 범위 밖이며 적용하지 않는다.

## Consequences

- 대화 세션 접근을 검증하고 다른 방문자의 이력이 조회/사용되지 않게 한다. 세션 ID만 바꾸어 타인의 이력에 접근할 수 없어야 한다.
- 전체 이력을 무제한 프롬프트에 넣지 않는다. 최근 이력 범위/요약 여부와 토큰 상한은 후속 설계에서 정한다.
- 이력 보관 기간, 저장 위치, 새로고침/재방문 시 복원 여부, 삭제/만료 동작은 아직 미정이다. 장기 기억이나 계정 기반 이력 목록을 자동 포함하지 않는다.
- 이전 답변 후 원문이 비공개로 바뀌면 후속 응답에서 그 내용을 다시 근거로 사용하지 않는다. 기존 화면에 이미 전달된 답변의 소급 제거 정책은 별도 설계한다.
- 생성/임베딩 모델과 세션 구현 기술은 이번 결정에 포함하지 않는다.
