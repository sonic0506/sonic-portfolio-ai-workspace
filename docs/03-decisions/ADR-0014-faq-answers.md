# ADR-0014: FAQ (Registered Question and Answer)

- Status: Accepted
- Date: 2026-09-17

## Context

사용자는 관리자가 등록한 질문·답변으로 답하고, 표현이 다른 같은 뜻의 질문("어디 거주중이신가요?")에도 등록 답변이 나가길 원한다. 측정 5(RAG_MEASUREMENTS)에서 짧은 질문끼리의 임베딩 거리는 같은 뜻과 다른 뜻이 겹쳤다(같은 뜻 최원 0.7338 > 다른 뜻 최근 0.6305). 거리 기준만으로 고정 답변을 내보내면 "어디서 일하세요?"에 "관악구에 삽니다"라고 답할 위험이 있다.

## Decision (2026-09-17 사용자 채택)

1. **FAQ를 RAG 검색 문서(`document_type = 'FAQ'`)로 색인한다.** 질문과 답변을 함께 담는다. 공개 여부는 FAQ의 `published`를 따른다.
2. **같은 뜻인지는 생성 모델이 판단한다.** 근거에 FAQ가 있고 질문과 같은 뜻이면 등록된 답변 문장을 그대로 쓰고 번호로 인용한다. 뜻이 다르면 쓰지 않는다. 거리 기준으로 모델을 건너뛰는 "빠른 길"은 두지 않는다(표본 부족).
3. **등록 방식은 질문 1개(결정 1-A)로 시작한다.** 다른 표현은 별도 테이블(`faq_alias`)에 둘 수 있게 스키마를 미리 만들고, 관리 화면·API는 필요할 때 연다(1-B).
4. 답하지 못한 질문에서 바로 FAQ를 만들 수 있고, 그 질문은 처리됨(RESOLVED)으로 바뀐다.

## Consequences

- FAQ 답변도 모델 호출 비용이 든다. 모델이 등록 문장을 다듬을 수 있으며 완전한 문자 그대로를 보장하지 않는다.
- 공개 사이트에 FAQ 전용 페이지가 없으므로 출처의 `url`은 `null`이다(`type = FAQ`).
- 프롬프트가 바뀌므로(ADR-0007 후속) 실제 모델 재측정 대상에 FAQ 질문을 포함한다.
