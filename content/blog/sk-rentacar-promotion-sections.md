## 개요

| 항목 | 내용 |
|---|---|
| 유형 | 기능 구현 |
| 시점 | 유지보수·추가 개발 기간 |
| 상태 | 서비스에 반영, 매달 새 콘텐츠 추가 |
| 관련 영역 | 메인 페이지, 프로모션 섹션, 어드민 콘텐츠 설정 |
| 나의 역할 | 유형별 콘텐츠 컴포넌트와 렌더링 구조 구현 |

## 1. 상황과 제약

메인 페이지에는 매달 새로운 프로모션 콘텐츠가 올라갔습니다. 섹션 유형은 룰렛, 타임어택, 기본형, 슬라이드형, 타임딜형처럼 모양이 서로 달랐습니다. 룰렛과 타임어택도 메인 페이지에 노출하는 섹션 유형의 하나입니다.

## 2. 검토와 판단

요구사항은 운영자가 어드민에서 콘텐츠 유형을 고르고, 유형에 맞는 차량과 이미지를 선택해 등록하면, 메인 페이지가 설정한 순서대로 섹션을 보여 주는 것이었습니다. 이 요구사항을 유형별 컴포넌트와 하나의 렌더링 컴포넌트로 나누는 구조로 구현했습니다.

## 3. 실행과 조율

- 섹션 유형마다 컴포넌트를 따로 만들었습니다.
- 하나의 렌더링 컴포넌트가 전달받은 유형에 따라 해당 섹션을 그리게 했습니다.
- 매달 새 콘텐츠를 올릴 때도 같은 구조를 썼습니다.

## 4. 결과와 확인

어드민에서 정한 유형과 순서대로 메인 페이지 섹션이 노출됐고, 참여 기간 동안 매달 새 콘텐츠를 같은 구조 위에 추가했습니다.
